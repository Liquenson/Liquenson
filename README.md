## 🏗️ Proyecto destacado

### gitops-stack — Pipeline GitOps de nivel productivo en AWS EKS

> Pipeline CI/CD completo que automatiza el ciclo de vida del software desde el commit hasta producción en AWS en menos de 5 minutos.

**Arquitectura:**
```
git push → Jenkins → Tests → Docker Build → ECR → Terraform → EKS → ArgoCD → Producción
```

**Stack:** Docker · Kubernetes · Jenkins · Terraform · AWS EKS · ECR · ArgoCD · Prometheus · Grafana · CloudWatch · CloudTrail · IAM

**Lo que incluye:**
- ✅ Pipeline Jenkins con aprobación manual antes de producción
- ✅ Infraestructura como código con Terraform (VPC, EKS, IAM)
- ✅ Gestión de usuarios y grupos IAM como código
- ✅ Registry privado en ECR con versionado automático
- ✅ Monitorización con Prometheus, Grafana y CloudWatch
- ✅ Auditoría completa con CloudTrail
- ✅ GitOps con ArgoCD — Git como única fuente de verdad
