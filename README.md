# Ruben Liquenson

**Cloud Platform Engineer \| DevOps Engineer**

Diseño, automatizo y opero plataformas cloud de nivel producción
utilizando **AWS, Kubernetes, Terraform y GitOps**.

Mi experiencia se centra en **Platform Engineering**, **Infrastructure

**Seguridad desde el diseño**, construyendo infraestructuras

de infraestructura cloud, automatización y plataformas DevOps modernas.
